虎虎建｜完整規則

1｜先放起始住宅

玩家輪流選一格放自己的起始住宅，彼此至少相隔 2 格。起始住宅四面全部開放，四個方向都能接住宅、巷弄或空地，本身不計住宅分。

2｜住宅牌 🏠

住宅牌只代表住宅，不再包含巷弄。成功放置一張住宅牌，放置者 +1。若住宅牆面直接碰到另一個住宅牆面，兩邊必須是相同材質：磚牆接磚牆、木構接木構、鐵皮接鐵皮、水泥接水泥。

3｜巷弄牌 🛣️

巷弄牌只代表道路，本身 0 分。巷弄必須一段一段連續；當連續巷弄第一次真正接通兩位不同玩家的起始住宅時，雙方各 +3。同一對玩家只計第一次。

4｜空地牌 🌿

空地 0 分，是萬用拼接面，可以與住宅、巷弄或空地相鄰。但空地不是道路，所以「起始住宅 → 巷弄 → 空地 → 巷弄 → 起始住宅」不算連通。

5｜回合

抽 1 張牌 → 旋轉 → 選合法位置 → 放置 → 即時計分 → 換下一位。住宅、巷弄、空地三種功能不混在同一張牌上。
